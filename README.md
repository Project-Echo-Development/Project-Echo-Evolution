# Project Echo Evolution

**Project Echo: Evolution** is a forge mod for Minecraft 1.16.4/5 with a focus around armor, weaponry, and loot blocks, a new take on the well loved Lucky Blocks, with our own ideas.

---

## Features

> ### Four tiers of Armor/Tools
> * Basic
> * Gold
> * Diamond
> * Carbon
> ### Loot Blocks
> * Currently 44 Drops

---

## Built For
- Minecraft **1.16.4/5**
